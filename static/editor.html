Unlock the editor

Enter the admin key to manage Projects, Achievements, and Tools. This key is set on the server as the ADMIN_KEY environment variable. It's exchanged for a session that expires after 12 hours — the key itself is never stored in your browser.

There is no default key. If ADMIN_KEY isn't set on the server, the editor stays locked — see the README.

Social links

These appear in the top bar and on the Chat page, in the order below. Add as many as you want. For the icon, paste a Font Awesome class like fa-brands fa-github — or an image URL if the logo you want isn't in that set. An email address is turned into a mail link automatically.

Background

Two layers behind every page. Both stop by themselves for visitors who ask their system to reduce motion.

Master discoveries

Lessons from building real systems, shown on the Tools page. Keep each one to a single idea — what you learned, and what you were building when you learned it. The section stays hidden until there's at least one entry.

Music playlist

Paste YouTube links and they become a player on the Tools page — visitors play them without leaving the site. A watch link, a share link, a Shorts link or a bare video ID all work. Leave the title blank to use YouTube's own. The whole section stays hidden until there's at least one track.

GitHub activity

Drives the contribution heatmap on the profile page. Just the username, not the full URL.
