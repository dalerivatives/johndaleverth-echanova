# Search engines: index the portfolio, stay out of the editor and the API.
#
# FORMAT RULES — both have bitten this file before:
#
# 1. No blank lines INSIDE a group. The original robots.txt standard (and
#    many non-Google crawlers) treat a blank line as the end of a group, so
#    any Allow/Disallow after one is silently dropped. Comments are fine;
#    empty lines are not. Blank lines only go BETWEEN groups.
#
# 2. No "Allow: /". Everything is allowed by default. A crawler that applies
#    the FIRST matching rule (instead of Google's longest match) stops at
#    "Allow: /" and never sees the Disallows.
#
# A crawler obeys ONLY the most specific group that names it and ignores
# "User-agent: *" once it has its own group — so the Googlebot groups below
# repeat the editor/API blocks, or Googlebot would be free to crawl them.
#
# Allowed paths, and why:
# - /api/health*: uptime monitors honour robots.txt, and a blanket
#   "Disallow: /api/" would quietly stop the keep-alive pings.
# - The icon files: Google won't show a favicon in search results for a URL
#   it isn't allowed to fetch — that is how a site ends up with the grey globe.
# - /api/settings, /api/content/, /api/github/: the public, read-only data
#   the home page loads to fill in its text, projects, achievements, tools
#   and GitHub activity. Without these, Google renders the page with those
#   sections empty. (Their write routes are admin-only regardless.)
