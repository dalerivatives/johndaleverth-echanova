PORTFOLIO V71 — LOGO & EDITOR UPDATE

Download BOTH files:
Johndaleverth_Portfolio_v71_Package_1_of_2.zip
Johndaleverth_Portfolio_v71_Package_2_of_2.zip

These are two normal, independently extractable ZIP files.
They are NOT split volumes: do not concatenate or rename them.

1. Create an empty folder, for example Portfolio_v71.
2. Extract Package 1 into that folder.
3. Extract Package 2 into that SAME folder. Merge the
   Johndaleverth_Portfolio folders if prompted.
4. Open Johndaleverth_Portfolio. Its voices folder must contain
   all four files ending in .part01, .part02, .part03 and .part04.
5. Run start.bat on Windows, or deploy the complete project.

No voice or application features were removed in this repair.
The app assembles the four voice model files automatically.
Both packages are required for the bundled voice model.
See UPDATE_v71.md for deployment requirements.
